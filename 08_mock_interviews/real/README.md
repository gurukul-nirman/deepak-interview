# real interviews

Debriefs of **real** interviews are saved here (`YYYY-MM-DD_<company>_<round>.md`, from
`../_templates/real_interview_debrief.md`). Command: `DEBRIEF <company> <round>`.
Each debrief updates `09_progress/applications_tracker.md`, `09_progress/gap_log.md` and the matching `10_revision/` file.
